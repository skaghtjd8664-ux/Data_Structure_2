# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

## 1. 실험 목적

동일한 무작위 정수 데이터에 대해 삽입 정렬과 쉘 정렬을 수행하고, 정렬 과정에서 발생하는 데이터 값 비교 횟수를 측정하였다. 쉘 정렬은 다음 두 가지 간격 수열을 사용하였다.

1. 기본 간격 수열: `n/2, n/4, n/8, ..., 1`
2. Knuth 간격 수열: `1, 4, 13, 40, 121, ...` 중 데이터 크기보다 작은 가장 큰 값부터 역순 적용

각 데이터 크기에서 세 알고리즘은 동일한 원본 배열의 복사본을 사용하였다. 배열 복사와 난수 생성에 필요한 연산은 비교 횟수에 포함하지 않았으며, 두 데이터 값의 `key`를 비교한 횟수만 측정하였다.

## 3. 구현 방법

### 삽입 정렬

현재 원소를 이미 정렬된 왼쪽 부분의 적절한 위치에 삽입하였다. 왼쪽 원소가 현재 원소보다 큰 동안 원소를 한 칸씩 이동한다. 데이터가 이미 정렬되어 있거나 거의 정렬되어 있으면 이동량과 비교 횟수가 작아지는 특징이 있다.

### 쉘 정렬 - 기본 간격

초기 간격을 `n/2`로 설정하고, 매 단계마다 2로 나누었다. 마지막 간격은 항상 1이 되도록 구성하였다. 큰 간격에서 먼저 멀리 떨어진 원소들을 정리한 후, 간격 1에서 최종 정렬을 수행한다.

### 쉘 정렬 - Knuth 간격

Knuth 수열 `h(k+1) = 3h(k) + 1`을 사용하였다. 데이터 크기보다 작은 가장 큰 간격부터 시작하여 `40, 13, 4, 1`과 같은 역순으로 적용한다. 이 방식은 간격 사이의 비율이 기본 절반 수열과 다르기 때문에 데이터의 이동을 분산시키는 효과가 있다.

## 5. 성능 분석

### 데이터 크기 증가에 따른 변화

삽입 정렬은 평균 및 최악의 경우 `O(n²)` 시간이 필요하다. 따라서 데이터 크기가 1,000에서 20,000으로 증가하면 비교 횟수가 매우 빠르게 증가한다. 특히 무작위 데이터에서는 원소가 삽입될 위치를 찾는 과정과 기존 원소를 이동시키는 과정에서 많은 비교가 발생한다.

쉘 정렬은 삽입 정렬을 여러 간격으로 수행한다. 큰 간격을 먼저 사용하여 멀리 떨어진 원소의 순서를 조정하기 때문에 마지막 간격 1에서 수행되는 삽입 정렬의 부담이 감소한다. 따라서 데이터 크기가 커질수록 일반 삽입 정렬과 쉘 정렬 사이의 비교 횟수 차이가 크게 나타나는 경향이 있다.

### 삽입 정렬과 쉘 정렬의 비교

삽입 정렬은 구현이 단순하고 작은 배열 또는 거의 정렬된 데이터에 효과적이다. 그러나 무작위 데이터가 많거나 데이터 크기가 커지면 비교 횟수가 급격히 증가한다.

쉘 정렬은 큰 간격을 이용하여 원소를 미리 이동시키므로 삽입 정렬보다 적은 비교 횟수로 정렬할 수 있다. 쉘 정렬의 실제 성능은 간격 수열의 선택에 영향을 받으며, 같은 데이터라도 어떤 간격을 사용하는지에 따라 비교 횟수가 달라진다.

### 기본 간격과 Knuth 간격의 차이

기본 간격은 매 단계마다 간격을 절반으로 줄인다. 구현이 간단하지만 간격이 규칙적으로 감소하므로 특정 데이터 배치에서는 비효율적인 비교가 남을 수 있다.

Knuth 간격은 `1, 4, 13, 40, ...` 형태로 증가하며, 실제 정렬에서는 큰 간격부터 역순으로 적용한다. 여러 간격이 서로 다른 원소 그룹을 정리하므로 마지막 간격 1에서 처리해야 하는 원소의 이동량을 줄이는 데 도움이 될 수 있다.

따라서 일반적으로 Knuth 간격이 기본 절반 간격보다 좋은 결과를 보일 수 있지만, 정확한 우열은 데이터 분포와 구현 방식에 따라 달라진다. README에는 프로그램의 실제 출력값을 넣고 두 수열의 비교 횟수를 직접 비교해야 한다.

### 간격 수열이 성능에 영향을 주는 이유

쉘 정렬에서 간격은 한 번의 삽입 정렬이 비교하는 원소들의 거리를 결정한다. 큰 간격은 전체 배열의 큰 순서 오류를 빠르게 줄이고, 작은 간격은 세부적인 순서를 정리한다. 간격이 적절하게 구성되면 각 단계에서 이미 어느 정도 정렬된 부분 배열을 만들 수 있어 마지막 간격 1에서 필요한 비교 횟수가 감소한다.

반대로 간격이 특정 데이터 구조와 맞지 않거나 이전 단계에서 충분히 정렬되지 않으면 마지막 단계에서 많은 비교가 발생할 수 있다.

## 6. 결론

실험에서는 데이터 크기가 증가할수록 삽입 정렬의 비교 횟수가 쉘 정렬보다 빠르게 증가하는지 확인하였다. 삽입 정렬은 작은 데이터나 거의 정렬된 데이터에는 적합하지만, 큰 무작위 데이터에서는 비효율적이다.

쉘 정렬은 간격을 사용하여 원소를 미리 이동시키므로 삽입 정렬의 단점을 완화한다. 기본 간격과 Knuth 간격은 모두 삽입 정렬보다 효율적일 수 있으며, 간격 수열에 따라 비교 횟수가 달라진다.

본 실험에서 최종적인 알고리즘의 우열은 실제 측정값으로 판단해야 한다. 각 데이터 크기별 비교 횟수와 증가 양상을 표에 기록하면, 데이터 크기가 커질수록 쉘 정렬의 장점이 더 뚜렷하게 나타나는지 확인할 수 있다.
